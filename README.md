5ch麻雀板の雀魂スレッドから友人戦募集を通知する、Windows / Ubuntu向け常駐アプリです。ウィンドウを閉じてもトレイで監視を続けます。

![アプリ画面](images/app.png)

## ダウンロード

[GitHub Releases](https://github.com/sakots/sureneco/releases/latest)からダウンロードできます。

- Windows：インストーラー（`Setup.exe`）またはポータブル版（`win.zip`）
- Ubuntu：DEB（`amd64.deb`）またはAppImage
- Android：ARM64向け署名付きAPK（手動導入用）。[導入・署名の注意](docs/android.md)を確認してください。AABはローカル保管のみで、GitHubには添付しません。GitHub公開とGoogle Play公開は別です。

Tauri版のWindowsではWebView2が必要です。インストーラーは必要に応じて導入します。Electron版から切り替える場合は[移行手順](docs/usage.md#electron版からの切り替え)を確認してください。

### Icedテスト版 v0.10.1

同じ[リリースページ](https://github.com/sakots/sureneco/releases/tag/v0.10.1)に、WebViewを使わないRust／Iced版を追加配布します。Windows x64 ZIPとLinux x64 tar.gzは、名前が`sureneco-iced_`で始まるものを選んでください。Tauri版の既存配布物・更新情報は変更しません。設定はIced専用で、自動更新はありません。旧Iced版を終了してから差し替えてください。[起動方法・Linux依存関係・検証上の制約](trials/iced/README.md)を確認してください。

## 使い方

1. 通知を受けたいスレッドのトグルをオンにします。
2. 友人戦募集が見つかると通知します。検出用正規表現やNG条件は設定で変更できます。
   新しいスレッドが候補一覧に追加された場合は、トグルがオフでもスレッド名を通知します（起動時の既存一覧は通知しません）。
3. 募集のルームIDをクリックしてコピーするか、「雀魂を起動」でコピーしてゲームを開きます。

Androidのバックグラウンド通知では、**「通知を有効にする」を押す前に**、ntfyの「設定」→「一般」→「デフォルトのサーバー」を **`https://push.oekakibbs.moe`** に変更して保存してください。通知先はntfyのデフォルトサーバーに自動作成されるため、ユーザー管理の接続先だけを設定しても代わりにはなりません。その後、通知を有効にし、発行されたユーザー名・パスワードをntfyの同じサーバーへ設定します。

レス数が1000を超えたスレッドは自動的に監視を解除し、画面にスレッド名と停止理由を表示します。1000レスちょうどでは監視を継続します。

ウィンドウを閉じるとトレイに常駐し、トレイメニューから終了できます。Ubuntuではトレイに対応したデスクトップ環境が必要です。トレイを作成できない環境ではウィンドウを閉じると終了します。

設定の保存先、ログイン時の自動起動、通知条件、アプリの更新、ブラウザー・Steamの指定などは[使い方](docs/usage.md)を参照してください。
