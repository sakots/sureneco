# Android画面と端末操作

## Purpose

Android端末で既存のスレッド選択、友人戦募集の閲覧、通知条件の設定を利用するための画面と端末操作を定義する。表示中だけ監視する初版の制限、権限拒否時の動作、端末内保存を利用者が理解できるようにする。

## ADDED Requirements

### Requirement: Android画面と監視状況の表示

Android版はスレッド一覧・友人戦募集・設定を提供し、surenecoを表示している間だけ監視することを画面内に明示しなければならない（SHALL）。幅360pxでも横スクロールせず、システムバーやソフトキーボードに操作を隠さない。既存の募集判定、NG、通知許可、設定検証を使用する。

#### Scenario: 狭い画面での利用

- **WHEN** Android端末の幅360pxの画面で各タブを表示する
- **THEN** 表示中のみ監視する案内が読め、設定を編集・保存でき、ルームIDをコピーできる

### Requirement: Androidの通知権限

Android版は募集通知に必要なOS権限を要求し、権限がない場合は利用不可を表示しなければならない（SHALL）。拒否時も一覧の閲覧と監視を継続できる。権限を許可した場合は表示中に新規募集をOS通知でき、通知からアプリを開ける。

#### Scenario: 通知を拒否する

- **WHEN** 利用者が通知権限を拒否する
- **THEN** 募集の閲覧と更新は動作し、通知権限がないことを表示する

#### Scenario: 通知を許可する

- **WHEN** 権限を許可して表示中に通知条件を満たす新規募集を取得する
- **THEN** その募集をOS通知し、通知を開くとsurenecoを表示する

### Requirement: Androidの設定保存と端末操作

設定、監視対象、取得済みレス番号はアプリ専用領域へ保存し、再起動後も保持しなければならない（SHALL）。5桁のルームIDはAndroidのクリップボードへコピーし、レスURLは外部ブラウザーで開く。デスクトップ用の実行ファイル選択・設定保存先変更・トレイ・ウィンドウ位置設定は表示しない。

#### Scenario: 再起動後の設定

- **WHEN** 通知条件と監視対象を保存してAndroidアプリを起動し直す
- **THEN** 保存内容を復元し、デスクトップ専用操作を表示しない

#### Scenario: ルームIDとレスURL

- **WHEN** ルームIDのコピーまたはレスを開く操作を行う
- **THEN** 半角5桁をクリップボードへコピーするか、検証済みレスURLを外部ブラウザーで開く
