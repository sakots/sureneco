# Androidの操作権限

## ADDED Requirements

### Requirement: Androidで利用できる操作の制限

Android版は既存の通信先制限と引数検証を保ち、通知権限、クリップボード、検証済みURLのブラウザー起動、アプリ専用領域への保存のみを端末操作として許可しなければならない（SHALL）。任意コマンド実行、実行ファイル選択、設定保存先の変更、GitHubからの実行ファイル更新はバックエンドでも拒否する。バックグラウンド監視用のサービスや不要なストレージ権限を要求しない。

#### Scenario: 専用操作の拒否

- **WHEN** Android版のWebViewからデスクトップ実行ファイルの起動または設定保存先の変更を直接要求する
- **THEN** 保存済み設定があってもバックエンドで拒否し、任意プロセスや外部ファイルへアクセスしない

#### Scenario: 最小権限での起動

- **WHEN** Android版を新規インストールして起動する
- **THEN** バックグラウンド常駐や共有ストレージ全体へのアクセス権限を要求せず、通知権限の拒否でアプリを終了しない
