# スレッド取得と監視

## Purpose

5ch麻雀板から雀魂スレッドの候補とレスを取得し、利用者が選んだスレッドを継続して監視する条件を定義する。候補期間、通信制限と、一覧と募集を独立して更新する間隔を扱う。

## Requirements

### Requirement: 板とレスの安全な取得

データ取得は以下の形式と通信制限を守らなければならない（SHALL）。

既定の板URLは [https://egg.5ch.io/mj/] 。板のsubject.txtをShift_JISで取得し、スレッドID、タイトル、レス数を解析する。subback.htmlと同じスレッド一覧を機械可読形式から読む。レスはdat/{id}.datから取得する。HTMLタグはテキストに変換し、外部HTMLを実行しない。5ch.io / 5ch.netのHTTPSの板URLだけを許可する。各リクエストは15秒、最大5MiB。リダイレクトは拒否する。HTTPエラーや取得形式の変化は画面に表示し、次回更新で再試行する。監視対象の取得は逐次実行する。

#### Scenario: 板データの解析

- **WHEN** 許可された板のsubject.txtを取得する
- **THEN** Shift_JISを解釈し、スレッドID・タイトル・レス数を解析する

#### Scenario: 通信制限

- **WHEN** 取得先が許可外、リダイレクト応答、15秒超過または5MiB超過となる
- **THEN** 取得を拒否または中断し、エラーを画面に表示する

### Requirement: スレッド候補の選択

スレッド候補は以下の条件で選択しなければならない（SHALL）。

スレッドタイトルがthread_title_regexに一致し、ng_thread_title_regexに一致せず、スレ立てからelapsed_days日以内なら候補に表示する。監視中のスレッドは候補期間を過ぎても取得する。正規表現は大文字小文字を区別しないJavaScript正規表現。空の除外正規表現は無効。

#### Scenario: 候補と監視対象の違い

- **WHEN** タイトル条件に一致するスレッドが候補期間を過ぎる
- **THEN** 候補には表示しないが、監視中なら取得を継続する

#### Scenario: 除外条件

- **WHEN** スレッドのタイトルが除外正規表現に一致する
- **THEN** 候補には表示しない

### Requirement: 独立した更新間隔

一覧と募集の取得は以下の更新条件に従わなければならない（SHALL）。

スレッド一覧は起動時と設定した間隔の経過時に取得する。レス数による臨時更新は行わない。取得失敗時は次の自動更新で再試行する。手動更新と設定保存時は一覧も更新する。友人戦募集の取得は一覧の更新間隔から独立させ、一覧を取得しない回も監視対象のdatを取得する。一覧のレス数はdat取得結果で更新する。

#### Scenario: 募集だけの定期更新

- **WHEN** 募集の更新時刻になり、一覧の更新時刻には達していない
- **THEN** 一覧を取得せず監視対象のdatを取得し、その結果でレス数を更新する

#### Scenario: 手動更新と設定保存

- **WHEN** 手動更新または設定保存を行う
- **THEN** スレッド一覧も更新する

#### Scenario: 取得失敗後の回復

- **WHEN** 自動更新の取得に失敗する
- **THEN** 次の自動更新で再試行する
