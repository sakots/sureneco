# Tauriのセキュリティ境界

## Purpose

WebViewとRustバックエンドの境界で許可する操作、引数と外部アクセス先を定義する。外部コンテンツや任意のコマンド実行へ権限を広げず、検証済みデータと保存済み設定だけでOS操作を行う。

## Requirements

### Requirement: 限定されたバックエンド操作

WebViewとOS操作の境界は以下の制限を守らなければならない（SHALL）。

WebViewからはmainウィンドウの限定コマンドだけを受け付ける。設定・スレッドID・ルームIDをバックエンドでも検証する。HTTP取得先は5ch.io / 5ch.netの板データに限定する。外部リンクは検証済み5chスレッドURL、雀魂の固定URL、更新用の固定リリースURLを既定ブラウザーで開く。指定アプリ起動には保存済みの起動設定だけを使い、シェルに文字列を渡さない。ナビゲーションと新規ウィンドウを制限し、多重起動を防止する。

#### Scenario: コマンドの呼び出し元と引数

- **WHEN** main以外のウィンドウまたは不正な設定・スレッドID・ルームIDから操作を要求する
- **THEN** バックエンドで拒否する

#### Scenario: 外部アクセスの制限

- **WHEN** 許可された板データや検証済みの外部URL以外への操作を要求する
- **THEN** 許可外のHTTP取得、ナビゲーションまたは新規ウィンドウを許可しない

#### Scenario: 多重起動の防止

- **WHEN** 既にアプリが起動している状態で再度起動する
- **THEN** 独立したアプリインスタンスを複数動作させない
