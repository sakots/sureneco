# スレネコチェッカー 0.9.0test テスターガイド

Androidの招待制ベータに参加する方向けの手順です。スレネコチェッカーは、5ch麻雀板の雀魂スレッドから友人戦募集を見つけて通知します。

## 参加前にお読みください

- **開発途中の検証版です。通知が遅れたり、届かなかったりする可能性があります。確実な通知が必要な用途には使わないでください。**
- 少人数の招待制です。APKや配布リンクの再配布は控えてください。Google Playで公開している版ではありません。
- 参加は任意です。試せる範囲だけで構いません。いつでも停止・終了できます。
- 通知には別アプリの **ntfy** が必要です。端末の通知許可、通信状態、電池設定、中継アプリの稼働によって受信できない場合があります。
- 同時接続時の購読開始失敗（403）と設定保存失敗（503）が既知の問題です。403の原因調査は中断中です。長時間消灯中の安定性も未確認です。
- この0.9.0test APKの実機でのインストール・起動・通知受信は未確認です。旧版の確認結果だけで本版の動作を保証するものではありません。

連絡先とテスト期間は、招待時に送られた案内を確認してください。連絡先が分からない場合は、インストール前に招待者へ確認してください。

## 1. 用意するもの

- Android 7.0以上のARM64端末。条件を満たす全機種での動作を保証するものではありません。
- インターネット接続。
- 招待者から受け取った次のAPK。

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `sureneco_v0.9.0test_android_debug.apk` |
| Androidで表示されるバージョン | `0.9.0-test`（配布名の0.9.0testと同じ版） |
| アプリ名 | スレネコチェッカー |
| SHA-256 | `d33de00006e8b4d1bae1a9573427def7476422af480a4ce949d13fbf202bce9d` |

Windowsでファイルを受け取った場合は、APKのあるフォルダーで次のコマンドを実行するとハッシュを確認できます。不一致ならインストールせず、招待者へ連絡してください。

```powershell
certutil -hashfile .\sureneco_v0.9.0test_android_debug.apk SHA256
```

## 2. インストールする

1. 招待者から受け取ったAPKをAndroid端末で開きます。
2. 必要な場合だけ、APKを開いたブラウザーやファイルアプリに「不明なアプリのインストール」を許可します。設定名は機種によって異なります。
3. インストール後は、その許可を元に戻します。
4. スレネコチェッカーを起動します。以前から使っている方は、設定が残っているかも確認してください。

警告や署名の不一致でインストールできない場合は、表示内容を記録して連絡してください。Play Protectなどの保護を一律に無効化したり、アプリのデータを消したり、アンインストールして強行したりしないでください。アンインストールすると端末内データが失われます。

ベータ中の更新は招待者が案内するAPKで行います。Google Playの自動更新では更新されません。将来の正式版へそのまま上書きできるかは未確認です。

## 3. ntfyを準備する

1. Google PlayまたはF-Droidからntfyをインストールします。
2. スレネコチェッカーの設定画面で「バックグラウンド通知」→「ntfyの準備・設定手順」を開きます。
3. 案内に従って、ntfyの接続先を指定された自前サーバーに設定します。既定の公開サーバーと取り違えないでください。接続先が表示されない場合は招待者へ連絡してください。
4. スレネコチェッカーとntfyの通知を許可します。ntfyの案内に従い、接続維持に必要な電池設定も確認します。変更した設定は、報告できるよう控えてください。

ntfyはバックグラウンド通知の中継を担当します。テスト中は強制停止しないでください。

## 4. 通知を有効にする

1. スレネコチェッカーで、サーバーに保存する情報の説明を読みます。同意する場合に「通知を有効にする」を押します。
2. 中継アプリとしてntfyを選びます。
3. 自動発行された接続先・ユーザー名・パスワードを、それぞれntfyのユーザー管理へ入力します。コピーボタンを使えます。
4. 以前の登録を編集する場合は、**ユーザー名とパスワードを両方**置き換えます。
5. スレネコチェッカーの表示が「監視中」になることを確認します。
6. 通知を受けたいスレッドのトグルをオンにします。

ユーザー名・パスワードは端末用です。他の人へ渡したり、報告に貼り付けたりしないでください。貼り付け後は必要に応じてクリップボード履歴を削除してください。

「監視中」にならない場合は、その時点の表示とntfyの接続状態を報告してください。連続した再登録や、設定の削除を繰り返す必要はありません。「監視中」でも、実際の通知受信を確認するまでは配送成功とは扱いません。

## 5. 普段の使い方で試す

まず通常の募集が通知されるか確認し、可能なら次の条件も試してください。テストのためだけにスレッドへ募集を投稿する必要はありません。

- スレネコチェッカーを開いているとき。
- 別のアプリを使っているとき。
- 画面を消しているとき。余裕があれば、普段の長時間消灯後も確認。
- 日常の移動などで、圏外から通信可能な状態に戻ったあと。

すべての条件を試す必要はありません。条件を一度に変えず、分からない項目は「未確認」としてください。無理な長時間試験、同時接続の負荷試験、サーバー停止は行わないでください。

通知が届いた場合は、募集投稿時刻と通知到着時刻を控えてください。消灯中なら消灯開始時刻と到着時の画面状態も分かる範囲で記録してください。届かなかった場合は、いつまで待って確認したかを記録します。到着確認のために画面を点けた場合は、その操作も報告してください。

## 6. 困ったとき

| 症状 | お願いしたい対応 |
| --- | --- |
| 403・購読開始失敗・ログインできない | エラー表示と接続状態を記録して連絡。連続再登録や認証設定の緩和はしない |
| 503・設定が保存できない | 時間を置いて「同期を再試行」を一度試し、時刻と結果を記録。解消しなければ連絡 |
| 通知が遅い・届かない | 端末の通知許可、ntfyの接続状態、画面・電池・通信状態を確認して報告。勝手に設定を初期化しない |
| 他人宛てと思われる通知が届いた／資格情報を漏らした疑い | 利用を停止し、招待時の窓口へ直ちに連絡。通知本文や秘密情報を公開しない |

失敗だけでなく、成功した条件も報告してもらえると助かります。

## 7. 報告テンプレート

招待時に案内された窓口へ、以下をコピーして送ってください。秒まで分からなければ分単位で構いません。推測で埋めず「不明」「未確認」と書いてください。

```text
発生日・タイムゾーン（例：日本時間）：
端末名／Androidバージョン：
アプリの版：0.9.0-test
ntfyの版／入手元（Google Play・F-Droid）：
試した条件（画面表示・別アプリ・消灯・圏外復帰など）：
消灯開始・終了時刻／変更した電池設定：
募集投稿時刻：
通知到着時刻（未着なら観察終了時刻）：
スレネコチェッカーの状態表示：
ntfyの接続状態：
期待した動作：
実際の動作・エラー表示：
直前の操作／再試行した時刻と結果：
```

**パスワード、認証トークン、通知先URL、トピック、私的な募集本文は送らないでください。** スクリーンショットも秘密情報を隠してください。端末のログ全体やデータベースをそのまま送る必要はありません。追加情報が必要なら、運用者から範囲と隠す箇所を案内します。

## 8. 一時停止・参加終了

- 一時停止する場合は、アプリ内の「監視を停止」を押します。圏外ではサーバーへの反映待ちになる場合があります。
- 参加を終了して登録も不要になった場合は、通信可能な状態で「サーバー登録を削除」を実行し、受付結果を確認してからアンインストールします。アンインストールだけを登録削除の代わりにしないでください。
- 削除の受付と、ntfy側のアカウント撤去完了は別です。受付表示だけで撤去完了とは判断しないでください。
- 端末紛失・アプリ起動不能・削除失敗の場合は招待時の窓口へ連絡してください。削除依頼にもパスワードやトークンを添付しないでください。

運用者向けの配布・中止判断は[ベータ実施方法](android-beta.md)に記載しています。
