# Android招待制ベータの実施方法

## 方針と現在の状態

2026/10/24時点では、既存テスター向けの少人数・招待制ベータとして実施します。不特定多数への一般募集、GitHub Releasesへの正式公開、Google Play提出は対象外です。人数は動作保証ではなく影響を限定するための運用上の制限です。安全な人数上限は未確認です。

本書と配布候補を準備した段階であり、新規テスターへの配布・参加・通知受信が完了したという記録ではありません。配布先、連絡窓口、初回参加者、実施期間は運用者が招待時に確定します。公開リンクを作る前に、招待者だけが取得できる配布先を用意してください。

ntfy同時購読403の調査は[中断記録](ntfy-403-investigation.md)のとおり中断したままです。本ベータのために原因調査・修正・負荷試験を再開しません。

## 運用者：招待と配布

1. 既存テスターを少人数招待し、連絡窓口、開始日、終了予定日、対象APK名とハッシュを伝えます。未確定の窓口のまま配布しません。
2. 下記の注意事項への同意を得ます。確実な通知が必要な人には参加を勧めません。
3. 招待者に限定したファイル共有でAPKと本手順を渡します。公開リポジトリーの添付や誰でも取得できるリンクは使わず、再配布を控えてもらいます。APKに共通のntfyログイン情報を添付しません。
4. 参加者ごとに端末・OS・APK名・参加日・導入結果を記録します。端末別資格情報、トピック、認証トークンは収集しません。
5. 初回導入は一人ずつ案内し、登録が「監視中」になることを確認してから次へ進みます。これは403の修正や回避保証ではありません。同時接続の負荷試験は依頼しません。

> Android版スレネコチェッカーの招待制ベータです。ntfyアプリが別途必要です。通知の遅延・未着、購読開始失敗、設定保存失敗が起こる可能性があり、確実な通知は保証しません。長時間消灯中の動作は確認途中です。既知の403問題は調査中断中です。参加は任意で、いつでも停止・登録削除できます。APKの再配布と資格情報の共有は控えてください。不具合は招待時に案内した窓口へ、秘密情報を除いて報告してください。

## 参加者：インストールと通知設定

1. 運用者から受け取ったAPK名・ハッシュを照合します。Windowsでは次のコマンドを使えます。

   ```powershell
   certutil -hashfile .\sureneco_v0.9.0test_android_debug.apk SHA256
   ```

2. 招待された配布元からAPKを開き、必要な場合だけ、そのインストールに使うアプリへ「不明なアプリのインストール」を許可します。導入後は許可を戻します。Play Protectなどの保護を一律に無効化しません。警告や署名不一致で止まったら運用者へ連絡し、データ削除やアンインストールで強行しません。
3. ntfyをGoogle PlayまたはF-Droidから導入します。スレネコチェッカーの「バックグラウンド通知」→「ntfyの準備・設定手順」を読み、指定の自前サーバー、通知権限、電池設定を確認します。
4. 保存する情報への説明を読み、同意した場合に「通知を有効にする」を押してntfyを選びます。自動発行された接続先・ユーザー名・パスワードをntfyへ設定します。既存登録の編集ではユーザー名とパスワードを両方置き換えます。
5. 資格情報を他人へ送らず、貼り付け後は必要に応じてクリップボード履歴を消します。「監視中」への移行を確認し、対象スレッドをオンにします。詳細は[通知設定](android.md#通知を設定する)を参照してください。
6. 初回の募集受信を確認します。届かない場合は成功扱いにせず、下記の項目を記録して報告します。ベータ中の更新も運用者が指定するAPKを使います。Google Playの自動更新は本配布には適用されません。

## 観察する条件と報告方法

通常利用の範囲で、画面表示中、別アプリ利用中、短時間消灯、可能なら長時間消灯後、日常の圏外からの復帰を記録します。全条件を一度に変えず、無理な長時間試験や本番サービス停止は行いません。長時間消灯・Dozeの成立条件が不明なら「未確認」と記入します。

```text
発生日・タイムゾーン：
端末名／Android版：
APKファイル名：
ntfy版／入手元：
条件（画面表示・別アプリ・消灯・圏外復帰など）：
消灯開始・終了時刻／電池制限設定：
募集投稿時刻：
通知到着時刻（未着なら観察終了時刻）：
スレネコの状態表示／ntfyの接続状態：
期待した動作／実際の動作：
エラー表示・操作手順：
再試行した場合は時刻と結果：
```

秒まで不明なら分単位と明記し、未着を遅延成功と混同しません。資格情報・トークン・通知先URL・トピック・私的な募集本文を報告へ貼り付けません。スクリーンショットも秘密情報を隠します。生のLogcatやDBは送らず、必要になった場合のみ運用者が収集範囲と伏せ方を案内します。

## 既知の問題と対処

| 問題 | ベータでの扱い |
| --- | --- |
| 同一IP・50同時開始の隔離試行で403 | 根本原因・本番影響は未確認。失敗を記録し、連続再登録や認証設定の緩和で押し通さない |
| 同時設定保存で503 | 設定失敗を成功扱いにしない。時間を置いて画面の「同期を再試行」を一度試し、結果を記録。解消しなければ連絡 |
| 消灯中の遅延・未着 | 成功例はあるが長時間の安定性は未確認。画面・電池・接続状態と時刻を記録 |
| デバッグAPKと将来の正式版の署名差 | 上書き可否は未確認。移行を保証せず、削除が必要なら事前に登録削除とデータ消失を案内 |

## 一時停止・終了・次段階への条件

- 正当な購読の403、初回登録不能、通常利用での継続的な未着が報告された場合は、新規招待をいったん止めます。資格情報漏えい・他人の通知受信の疑いでは、影響する参加者に利用停止を案内し、運用者へ直ちに連絡します。調査中断を自動解除したとは扱いません。
- 終了する参加者はアプリ内で「監視を停止」、不要なら「サーバー登録を削除」を実行してからアンインストールします。圏外時の停止は反映待ちになり得ます。削除受付とntfy側撤去完了は別です。紛失・起動不能の場合は招待時の窓口へ削除を依頼し、資格情報を送らないでください。
- 運用者は参加者数、試した条件、成功・失敗・未確認、未着と遅延、停止・削除依頼の処理状況をまとめます。今回の配布先・参加・受信実績はまだ未確認です。
- 一般募集への拡大は403の原因と本番影響、設定保存503の利用者への扱いを評価してから判断します。Play配布は別途[提出準備](google-play.md)の署名・versionCode・ポリシー・テスト条件を満たす必要があります。少人数での成功だけで正式公開へ進みません。
